# Battlegrounds

Мод для Minecraft 1.20.1 (Fabric): королевская битва — оружие, обвесы, гранаты, позы, наклоны, перелезание и вид из-за плеча.

Нужны Fabric Loader и Fabric API. Готовый .jar — в разделе Releases.

## Управление
- ЛКМ — стрелять, ПКМ — прицелиться
- R — перезарядка, B — режим огня
- C — присесть, Z — лечь
- Q / E (с оружием в руках) — наклон влево / вправо
- Пробел у препятствия — залезть на уступ до 2 блоков или перелезть в окно
