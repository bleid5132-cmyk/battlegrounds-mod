# Battlegrounds

Мод для Minecraft 1.20.1 (Fabric): королевская битва — оружие, обвесы, гранаты, позы, наклоны, перелезание и вид из-за плеча.

Нужны Fabric Loader и Fabric API. Готовый .jar — в разделе Releases.

## Управление
- ЛКМ — стрелять, ПКМ — прицелиться
- R — перезарядка, B — режим огня
- C — присесть, Z — лечь
- Q / E (с оружием в руках) — наклон влево / вправо
- Пробел у препятствия — залезть на уступ до 2 блоков или перелезть в окно
- G (с оружием в руках) — меню обвесов

## Оружие
M416, AKM, M16A4, SCAR-L, QBZ, G36C, AUG, Beryl M762, Groza, Mk47 Mutant, ACE32, K2, FAMAS.

## Обвесы
Коллиматор, голограф, 2x, 3x, 4x, 6x; компенсатор, пламегаситель, глушитель; вертикальная, угловая, полурукоятка, упор для пальца, лёгкая; увеличенный, быстрый и увеличенный быстрый магазины; тактический приклад.
